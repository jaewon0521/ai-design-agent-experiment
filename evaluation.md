# Evaluation

## Objective

Measure how different AI design skills influence the final UI.

## Primary criteria

### 1. AI Slop

- Generic layout
- Repeated card patterns
- Generic typography
- Generic color palette
- Excessive gradients
- Excessive rounded corners
- Generic SaaS patterns
- Meaningless decorative elements

### 2. Domain fit

- Does the UI reflect a team-management product?
- Is information hierarchy appropriate?
- Does the UI support the team's workflow?

### 3. Visual identity

- Does the product have a recognizable visual direction?
- Does it feel interchangeable with another SaaS?

### 4. UX

- Is the information hierarchy clear?
- Are important actions easy to discover?
- Are states understandable?

### 5. Consistency

- Typography
- Spacing
- Color
- Components
- Interaction patterns
